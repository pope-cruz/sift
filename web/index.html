What happens after you send it.

01
Send anything

A PDF, a screenshot, a link, or a half-formed thought.

02
Understand it

sort reads it and works out what it actually contains.

03
Sort it

A deadline, a place, an opportunity, a fact — each kept with its source and connected to what you sorted before.

04
Bring it back

Ask for it later, or get a reminder when the information supports one.

Prototype transparency

What sort stores

What you send it, the fields it sorts out of that, and a pointer back to the source those fields came from.

How sorted context is isolated

Sorted context is scoped to the conversation it arrived in and is not shared between people.

What is deterministic here

Every message, attachment, and result in the demo above is scripted local data. This page makes no network or model calls.

View prototype details ▾
Deleting saved information

Per-item and full-history deletion are handled in the working prototype, not on this page. Retention behavior is documented alongside it.

Model use

This page calls no model. The working prototype’s model and data-use policy is documented with the project.

Scope of this build

Four scenarios, fixed content, no signup, no accounts, no storage. It demonstrates the sorting behavior, not the full system.
